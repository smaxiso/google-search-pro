Google Search Pro
=================

**🌐 [Try it Live: https://googlesearchpro.netlify.app/](https://googlesearchpro.netlify.app/)**

**Google Search Pro** is a sophisticated web application that enhances Google searches by providing an intuitive interface for building advanced Google dork queries. With a modern Material Design 3 interface and powerful search capabilities, it makes complex search operations accessible to everyone.

## 🔗 Quick Links
- **🚀 Live Demo**: [https://googlesearchpro.netlify.app/](https://googlesearchpro.netlify.app/)
- **📂 Source Code**: [GitHub Repository](https://github.com/sumitcr7/google-search-pro)
- **📖 Documentation**: This README

🚀 Features
--------

### Advanced Search Capabilities
*   **Smart Query Building**: Automatically constructs optimized Google dork queries
*   **Category-Based Search**: Specialized searches for Books, Music, Videos, Software, and Images
*   **File Type Filtering**: Extensive file type support with category-specific options
*   **Site-Specific Search**: Limit searches to specific domains or websites
*   **File Size Filtering**: Filter by small, medium, or large file sizes
*   **Date Sorting**: Sort results by modification date

### Enhanced User Experience
*   **Real-time Query Preview**: See your generated dork query as you type
*   **Copy to Clipboard**: Easy copying of generated queries
*   **Form Validation**: Smart validation with helpful error messages
*   **Keyboard Shortcuts**: Power user shortcuts for faster operation
*   **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices

### Modern Interface
*   **Material Design 3**: Latest Google design system with beautiful animations
*   **Subtle Animations**: Smooth transitions and hover effects
*   **Toast Notifications**: Elegant feedback system
*   **Floating Background Elements**: Dynamic visual appeal
*   **Dark/Light Theming**: Automatic color adaptation

🎯 How to Use
----------

1. **Enter Search Terms**: Type your search query in the main search box
2. **Select Category**: Choose from Books, Music, Videos, Software, or Images
3. **Choose File Type**: Pick specific file types (auto-populated based on category)
4. **Add Filters**: Optionally specify a website, file size, or sorting preference
5. **Preview Query**: Watch the generated Google dork query update in real-time
6. **Search or Copy**: Click Search to open in Google, or Copy to use elsewhere

### ⌨️ Keyboard Shortcuts
- `Ctrl + Enter`: Execute search
- `Ctrl + R`: Clear form
- `Ctrl + C`: Copy generated query (when not in input field)

🚀 Getting Started

- Always up-to-date

### 💻 **Local Development**
1. **Clone the repository**:
   ```bash
   git clone https://github.com/sumitcr7/google-search-pro.git
   ```
2. **Navigate to project directory**:
   ```bash
   cd google-search-pro
   ```
3. **Open in browser**:
   - Simply open `index.html` in any modern web browser
   - Or use a local server: `python -m http.server 8000`
